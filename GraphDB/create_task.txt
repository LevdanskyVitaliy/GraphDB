Тема: Графовая база данных: Оркестрация мультиагентных ИИ-систем (AI Agents Workflow)

Описание предметной области:
Разработка графовой БД для управления, отслеживания взаимодействия и мониторинга локальных и облачных автономных ИИ-агентов,
LLM-моделей, системных задач и рабочих сред (серверов/хостов). Система позволяет анализировать пайплайны "coding",
выявлять узкие места в выполнении фоновых скриптов и отслеживать, через какие провайдеры (API) работают агенты.

Узлы (Nodes):

Agent (Агент) — Атрибуты: ID, Name (например, MrCron, StudyAgent), Role.

Model (LLM-модель) — Атрибуты: ID, Provider (например, Qwen Portal, Llama, Ollama), Version.

Task (Системная задача) — Атрибуты: ID, Description (например, Обновление API Dashboard, Cron-уведомление), Priority.

Environment (Среда выполнения) — Атрибуты: ID, OS (macOS, Linux), Hostname (например, admin).

Ребра (Edges):

UsesModel (Агент использует модель) — Атрибуты: API_Key_Name, RequestLimits.

Executes (Агент выполняет задачу) — Атрибуты: Status, LastRunDate.

HostedOn (Модель поднята на среде) — Атрибуты: Port, isLocal (boolean).

WritesTo (Задача записывает данные в другую Задачу/БД) — Атрибуты: Protocol (API, SQL).

DependsOn (Задача зависит от другой задачи) — Атрибуты: Delay.

Задачи для SQL (MATCH и SHORTEST_PATH):

Найти все системные задачи (Task), которые выполняются агентами (Agent), использующими модели локального хостинга на базе среды macOS.

Определить, какие задачи пострадают (через связь DependsOn), если отключится провайдер модели Qwen Portal.

Найти кратчайший путь передачи данных от агента планирования (MrCron) до финального дашборда менеджера задач.
